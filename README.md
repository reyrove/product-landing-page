# Product Landing Page

A modern, fully responsive product landing page designed to showcase product features, demo videos, pricing plans, and email subscription functionality.

[Live Demo](https://reyrove.github.io/product-landing-page/)

## Features

- Fixed navigation header for easy access
- Responsive layout that adapts to all devices
- Features section highlighting product benefits
- Embedded product demo video
- Pricing plans with multiple tiers
- Email subscription form
- Clean cyan and dark color scheme
- Smooth scrolling navigation

## Sections

1. **Header** - Fixed navigation bar with logo and links
2. **Features** - Showcases product key features
3. **Video Section** - Embedded product demonstration video
4. **Pricing** - Multiple pricing plans (Basic, Pro, Premium)
5. **Subscribe** - Email newsletter subscription form

## Technologies Used

- HTML5
- CSS3 (Flexbox, Media Queries)

## Installation

1. Create a new folder on your computer
2. Save the following files in that folder:
   - `index.html` (the HTML structure)
   - `styles.css` (the styling)
3. Open `index.html` in any modern web browser
